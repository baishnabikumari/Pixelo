# Pixelo

Pixelo is a small pixel art editor made with HTML, CSS and JavaScript.

we made it to draw pixel art on a 32x32 canvas and also work with simple frame animations. 
Everything runs directly in the browser.

## Features

- 32x32 pixel canvas
- Pencil and eraser
- Fill bucket
- Color picker
- Line tool
- Rectangle tool
- Ellipse tool
- Filled shapes
- Dithering brush
- Zoom and pan
- Pixel grid
- Multiple layers
- Layer visibility
- Layer opacity
- Rename and delete layers
- Undo and redo
- Custom color palette
- Import colors using hex values
- Import palette from a URL
- Extract colors from an image
- Lock drawing colors to the palette
- Multiple animation frames
- Rename and delete frames
- Live animation preview
- Adjustable FPS
- Onion skin
- PNG import
- PNG export
- Sprite sheet export
- Sprite sheet JSON export
- GIF import/export UI
- X and Y symmetry controls
- Local project saving
- Share project link option

## Controls

| Key | Action |
| --- | --- |
| B | Pencil |
| E | Eraser |
| G | Fill |
| I | Color picker |
| L | Line |
| R | Rectangle |
| O | Ellipse |
| D | Dither |
| Ctrl + Z | Undo |
| Ctrl + Y | Redo |
| Space + Drag | Pan canvas |
| Mouse Wheel | Zoom |
| 0 | Center canvas |

You can also hold Shift while drawing rectangles or ellipses to keep the shape square.

## Animation

Frames are shown at the bottom of the editor....

You can add more frames, rename them, delete them and preview the animation directly inside Pixelo.

The FPS slider can be used to change the animation speed.

Onion skin can also be turned on to see the previous and next frames while drawing.

## Layers

Each frame can have multiple layers.

You can:

- add layers
- rename layers
- hide or show layers
- change opacity
- delete layers

## Palette

Pixelo has a small color palette system.

You can enter hex colors manually or paste a URL containing hex colors.

There is also an option to extract colors from an image and a palette lock option which keeps drawing colors close to the selected palette.

## Import and Export

Pixelo can import PNG images into the editor.

Projects can be exported as:

- PNG
- Sprite sheet PNG
- Sprite sheet JSON
- Animated GIF

GIF files can also be imported and split into frames.
